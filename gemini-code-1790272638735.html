About

Matheus — Formula SAE team member focused on vehicle dynamics and data acquisition. Splits time between MATLAB analysis tooling, embedded firmware, and simulation, mostly in service of getting cleaner data out of the car and turning it into decisions the engineering team can use.

Projects

A working set of the tools currently in use on the team.

fsae_lap_timer_new.m

Real-time lap timing & setup comparison

A MATLAB GUI application for live lap timing, run comparison, and pilot/setup management, spanning several major versions. Pairs with a companion ESP32 + HC-SR04 beacon running interrupt-driven timing with temperature-compensated speed of sound. Generates HTML reports with lap charts, statistics, and setup comparisons.

PTECU_1.csv

CVT powertrain visualization tool

A multi-tab, dark-mode MATLAB tool for logged ECU data from the car's CVT powertrain. Time-series plots, RPM-vs-speed scatter with CVT ratio overlays, histograms, and cumulative distance/ratio tracking — built with careful handling of sensor faults and conversion constants.

Steering & chassis signal analysis

A multi-tab analysis script for steering angle, pedal, roll, and lateral acceleration signals, including cumulative integral and derivative views of steering input, with ongoing work on plot styling to separate raw data from smoothed overlays.

J13 — brake test analysis

Brake test data pipeline

A MATLAB pipeline that applies a Butterworth bandpass filter to IMU/CAN logger data and integrates acceleration to derive speed and distance, with gravity/lean compensation for a leaning vehicle and sign-convention checks throughout.
